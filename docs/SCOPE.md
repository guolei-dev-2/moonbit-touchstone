# MoonTouchstone 0.3.0 范围与验收终点

0.3.0 在既有格式/频段计算上补齐混合模、噪声网络与放大器计算；本文件替代 0.2.x 中“混合模/噪声仅保存、遇到即拒绝计算”的开发终点。实际 API 与独立回执见 [RF 0.3](RF-0.3.md) 和 [本轮检查](../evidence/review-20261023/CHECKS.json)。

| 职责 | 交付验收条件 |
|---|---|
| 文件与物理模型 | 1.0/1.1/2.0/2.1、RI/MA/DB、Hz–GHz、单/逐端口正实参考阻抗、全/上下三角和二端口顺序；旧 Y/Z/H/G 归一化还原 SI，保留信息及噪声/模态元数据 |
| 混合模 | 任意有效差分对、成对 D/C 与保留 S 端口；正确电压/电流及参考阻抗变换；S/Y/Z 正逆、文件模式顺序还原；SDD/SDC/SCD/SCC/CMRR |
| 二端口噪声 | Fmin/Γopt/Rn 与相关矩阵互转，频率插值、同时级联网络与噪声、左右夹具去嵌入、给定 Γs 的 F 与噪声圆；缺失噪声与显式无噪声的含义须明确 |
| 参数与端接 | S/Y/Z/H/G/ABCD/T 在数学可表示时互转；正实参考阻抗重归一化；任意复反射/复负载端接求 Schur 降维；不以扰动掩盖奇点 |
| 射频分析 | K/abs(Δ)/μ/μ′/MSG/MAG、增益圆；互易/全矩阵无源性、群时延、回损/插损/VSWR；无穷与未定义结果不能伪造为普通有限数 |
| 频段任务 | 离散采样点阈值/通带波动、原始频点定位、覆盖不足和无数据的无法判定；不是连续频带认证 |
| 可复现性 | MoonBit 实现核心；独立 scikit-rf/NumPy 数值对照；固定 MoonBit 版本、两个后端测试、公共接口及离线模块包 |

数值与输入边界：当前有限 double 网络模型及正实、频率不变的端口参考阻抗。任意复负载是端接能力，不等于任意复参考阻抗的全套功率波定义。病态矩阵、无定义的变换和不可实现的噪声状态明确失败。各类具体判据和模态不等阻抗约定在 RF 指南说明。

文件预算沿用既有模型：1–32 端口、至多 100000 频点及 2000000 复数值、64 MB 文本；这属于本实现的资源配置，不是 Touchstone 标准对尺寸或精度的限制。注释/排版不逐字保留；二进制/稀疏扩展、仪器校准、全频因果模型及器件认证不是本次交付职责。

完整终点指上述职责均有可执行接口、独立正反例及实际文档消费，六项工程检查通过且回执绑定交付源码；不是仅解析后存储元数据。源码完成、远端 CI、注册表发布、报名附件上传和赛事结论分别记录。

标准：[IBIS Touchstone 2.1](https://www.ibis.org/touchstone_ver2.1/touchstone_ver2_1.pdf)，含 1.0/1.1 兼容规则及附录 A 模态变换。参考实现与许可见 [THIRD-PARTY](../THIRD-PARTY.md)。

2026-10-28经明确授权增加一个本地应用拓展：二端口实际源/负载传输功率增益GT，复反射Γs/Γl、逐频点线性/dB值及零/奇点/上溢/下溢状态；匹配默认值、CLI、纯MoonBit/文件消费者及独立四波方程验收见[功能契约](TRANSDUCER-GAIN.md)。此拓展不扩大文件格式、端口预算、参考阻抗定义或仪器校准范围；不包含主动负阻终端增益、频变Γ数组、匹配综合、非线性或稳定性认证。

10轮经授权补充[物理终端Ω入口](IMPEDANCE-GAIN.md)：有限复Zs/Zl、Re(Zs)>0和Re(Zl)≥0的二端口GT，独立方法/命令以避免Γ/Ω混淆。原参考阻抗和文件范围不变，既有Γ合同保持；不包含无穷Z、主动负阻GT、频变终端数组或新校准算法。

11轮经授权增加[GT采样限值报告](GAIN-CHECK.md)：复用Γ/Ω迹线，闭区间有限dB界限、状态计数、极值/原索引与覆盖判定；沿用至少一个样本、fail优先和不插值的采样约定，迹线最多100000点。它不改变05—10数学算法，也不扩展连续频率、匹配优化、CSV或新格式职责。

12轮经授权增加可选[GT回执与复核](GAIN-RECEIPTS.md)：实际输入字节的SHA256/长度、有效Γ/Ω查询与原报告组成回执；先核输入身份，再由当前实现复算并比较完整解析JSON。复现与采样判定分别记录，已有gain-check格式、数值/报告算法与公共库API不变。验收包括实际文件、改字节/改结果/改条件、JSON排版、非法回执及独占输出；不包含签名、公证、历史时点证明、执行文件认证、任意命令重放或新的RF算法。

13轮经授权将GT的逐点审阅CSV纳入本地拓展，见[GAIN-CSV](GAIN-CSV.md)：复用既有迹线和采样限值规则，导出每个选中原始点、五态、空值、逐点标志与整段判定/覆盖。只新增纯MoonBit渲染API和独立文件命令，保留旧API、算法、JSON及回执协议；没有通用CSV读写器、表格引擎、XLSX或新RF计算。11轮当时不包含CSV的历史终点不变。

16轮经授权补充[显式端接文件导出](TERMINATE-FILE.md)：复用既有terminate_ports与Document写出，单独命令生成降维后的单端S Touchstone，保留输入已有信息行，支持随后二端口GT/报告/回执消费。新入口拒绝带噪文档，不伪造端接噪声变换；旧terminate JSON和合法输入不变。没有新公共库API、RF算法、自动频率对齐、多端口噪声模型或链式身份认证。
